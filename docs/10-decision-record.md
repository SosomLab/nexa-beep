# 10 · 통합 결정 기록 (Decision Record)

> 이 프로젝트의 **개발 방향·기술 요소 확정 기록**. 변경 시 **과거 항목을 지우지 말고** 새 항목/개정으로 정정하며 "정정"임을 명기한다([16 §2-5](16-doc-git-conventions.md#2-문서-작성--필수-규칙-8)).
> 대안 비교가 필요한 큰 결정은 별도 **ADR 문서**로 남기고 §2 색인에 건다.

## 0. 관통 원리 — "봉투만 본다"

> 이 프로젝트의 보안 설계는 계층마다 따로 만든 것이 아니라 **같은 패턴 하나가 반복된 결과**다.
> **어떤 계층도 자기 일을 하는 데 필요한 만큼만 보고, 내용은 보지 않는다.**

| 계층 | **봉투**(볼 수 있는 것) | **내용**(볼 수 없는 것) |
|---|---|---|
| **릴레이 서버**(v2 · [ADR-0003 §5](09-adr-0003-transport-abstraction.md)) | 목적지 노드 · 크기 · 타이밍 | 메시지 · 파일 · 이름 |
| **발견 패킷**([ADR-0002 §2](08-adr-0002-discovery-transport.md)) | 존재·주소·능력 — **미검증 힌트** | 아무것도 주장하지 않는다(신원은 핸드셰이크로만) |
| **전송 계층**([ADR-0003](09-adr-0003-transport-abstraction.md)) | 경로·바이트 스트림 | 평문(암호화는 전송 **위**) |
| **`.beepq` 격리물**([ADR-0004 §2](11-adr-0004-quarantine.md)) | 메타·해시·등급 | **봉인된 본문** — 로더가 해석 불가 |
| **기기 목록**(v2 · [ADR-0007 §4](20-adr-0007-multi-device-identity.md)) | UserId 지문 · 기기 공개키 · 버전 · 서명 | 대화 · 첨부 · 기록 |
| **저장 세그먼트**([ADR-0005 §4](17-adr-0005-history-at-rest.md)) | 헤더(라우팅용) | AEAD로 봉인된 레코드 |
| **검색 인덱스**([ADR-0005 §5](17-adr-0005-history-at-rest.md)) | HMAC 토큰 | 원문 토큰 |
| **계측 레저**([13 §6](13-code-design-standards.md)) | 행위 종류·횟수·바이트·결과 | 내용 · 파일명 · 평문 상대 |
| **로그**([13 §7](13-code-design-standards.md)) | `action_id` · 상태 전이 | 내용 · 경로 · 키 |

> **새 기능을 설계할 때의 질문** — *"이 계층의 봉투는 무엇이고 내용은 무엇인가?"*
> 답이 안 나오면 그 계층은 필요 이상을 보고 있다.

|---|---|
| **한 노드**가 유선·무선·IPv4/IPv6로 **여러 경로**에서 발견 | ✅ **병합** — 같은 키 지문이므로 목록에 **1개**(FR-D-6) |
| **다른 PC** 두 대가 같은 사람의 것 | ❌ **병합하지 않는다** — 다른 지문 = 다른 노드 |
| **개정(DR-20)** — 두 PC가 **서명된 같은 `UserId`** 를 제시 | ✅ **한 사람으로 접어 표시**(v2). 서명 검증에 실패하면 위 규칙대로 **별개**. 서명 없는 "같은 사람" 주장은 **믿지 않는다** |
| 표시 이름이 같은 노드 둘 | ❌ 별개. **이름은 표시일 뿐 신원이 아니다** |

> 혼동을 줄이기 위해 표시 이름 기본값을 **호스트명 기반**으로 둔다(FR-D-9) — "홍길동-맥북"과 "홍길동-데스크톱"이 자연히 구분된다.
> ⚠️ **DR-20 이후에도 이 표의 원칙은 그대로다** — 병합의 근거는 언제나 **암호학적 증거**이지 이름·IP·사용자 주장이 아니다.

### DR-8 보충 — 2모드가 설계에 강제하는 것

| 항목 | 로컬 직접 모드 | 릴레이 모드 | ⇒ 공통 설계 요구 |
|---|---|---|---|
| 신원 | 기기 키쌍(자체 생성) | 동일 | **키 지문이 유일한 신원** — 계정 개념을 도입하지 않는다 |
| 주소 | LAN IP·포트(수시 변동) | 서버상의 논리 주소 | 상위 계층은 IP를 모른다. **신원 → 전송 해석은 전송 계층 안에서만** |
| 발견 | 멀티캐스트/브로드캐스트 | 서버 디렉터리 | 발견 결과는 동일한 `Peer` 표현으로 수렴 |
| 암호화 | 단말 간 E2E | 단말 간 E2E(**서버는 봉투만 본다**) | 암호화는 전송 계층 **위**에 둔다 — 전송이 바뀌어도 그대로 |
| 오프라인 | 상대 부재 시 로컬 큐 | 서버 보관 | 큐는 인터페이스로, 구현은 모드별 |
