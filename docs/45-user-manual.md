## 1. 시작하기 — 실행이 곧 참여

설치본을 열거나 포터블 `nexa-beep`을 더블클릭하면 **바로 목록 화면**이 뜬다. 서버 주소·계정·상대 등록은 없다.
같은 로컬 네트워크(LAN)에서 실행 중인 상대가 **자동으로 목록에 나타나고**, 고르면 즉시 암호화 대화가 시작된다.

| 라이트(시스템 추종 기본) | 다크 |
|---|---|
| ![목록 · 라이트](img/manual/list-light.png) | ![목록 · 다크](img/manual/list-dark.png) |

**화면 읽는 법**

| 자리 | 뜻 |
|---|---|
| 툴바 왼쪽 5개 | **재발견**(목록 새로 고침) · **주소로 추가**(⌘/Ctrl+K — 다른 망의 상대를 IP/DDNS로) · **격리함**(받은 파일 보관·승인) · **보관함**(격리 해제된 파일) · **대화함**(열린 대화 목록·공지) |
| 툴바 오른쪽 | **연결 아이콘**(서버 연결 상태 — Managed일 때) · **내 아바타** = 클릭하면 **내 프로필** |
| 필터 바 `Via` `On` `Who` | 경로(전체·LAN·서버·인터넷·그룹) · 접속(전체·온라인·오프라인) · 신뢰(전체·대조 완료·핀·처음 본 상대) 칩 — **AND**로 겹친다 |
| 행의 점 | 🟢 온라인 · ⚪ 오프라인 · 🔴− 방금 끊김 · 오른섽 ✔ 배지 = **핀(TOFU)** · 파란 실 배지 = **대조 완료** |
| 상태바 | 마지막 사건 한 줄 + `수신 :포트`(이 실행의 세션 포트) |

> 🆕 **테마는 OS를 따라간다**(v0.2.11~) — 설정 › 모양 › 테마 = 시스템/라이트/다크. 창 장식(제목 표시줄)까지 같이 바뀐다.
> 🆕 **오프라인이어도 행이 남는다**(v0.2.15 예정 · 09-03 수정) — 대화 이력·핀·수동 주소가 있는 상대는 상대가 꺼져도 목록에서 사라지지 않는다([§5](#5-목록-관리--오프라인-행우클릭-메뉴프로필)).

## 2. 대화

목록에서 상대를 **더블클릭**하거나 **Enter**를 누르면 대화가 열린다. 첫 대화면 세션을 먼저 맺는다(1초 안쪽 · 상태바 `대화 열림`).
대화 창은 **두 가지 모드** 중 하나다 — 설정 › 대화 › **대화 창 모드**(다음 대화부터 적용).

| 상대별 **별도 창**(Alice) | **단일 창** — 목록 자리에서 열리고 Esc로 목록 복귀(Bob · 다크) |
|---|---|
| ![별도 창](img/manual/chat-separate-light.png) | ![단일 창](img/manual/chat-single-dark.png) |

- **Enter = 전송 · Shift+Enter = 줄바꿈 · Esc = 목록**. 오른쪽 아래 `일반` = 이 메시지의 등급(일반/알림/긴급 — 누르면 바꾼다 · 상대의 알림 세기는 **상대가** 정한다).
- 내 말풍선 왼쪽 **파란 점 2개** = 상대가 받았고 읽었다(수신·읽음 확인 — 설정 › 대화에서 보내기 여부 선택 · "읽음" 강제는 없다).
- 첫 대화에는 회색 안내가 붙는다 — *"이 상대는 아직 지문 대조 전입니다"*. 진짜 그 사람인지 확인하려면 `/fingerprint` → 전화·대면 등 **다른 채널로 숫자를 맞춘 뒤** → `/verify`([§5-3](#5-3-프로필-카드--키-지문-대조)). 대화 자체는 대조 없이도 **항상 암호화**된다.
- **`/`로 시작하면 명령**(상대에게 나가지 않는다): `/help` `/fingerprint` `/verify` `/trust` `/notice`(이 메시지 알림 등급) `/urgent` `/close`. `/`로 시작하는 문장을 보내려면 `//`.
- 상대가 꺼져 있어도 보낼 수 있다 — **오프라인 큐**(200건 · 재시작 유지)에 들어가 상대가 나타나면 전달된다(내 PC가 켜져 있을 때).

## 3. 파일·이미지 보내기

세 가지 방법이 전부 같은 길을 탄다 — ① 대화 창에 **끌어다 놓기** ② 클립보드 이미지를 **⌘/Ctrl+V** ③ CLI `/send`.

> 🆕 **⌘/Ctrl+V = 이미지 전송**(v0.2.14 — 3-OS 자체 구현). 스크린샷을 찍고 대화 창에서 붙여넣으면 **PNG 파일로 전송**된다.
> Windows·macOS·Linux 어디서도 외부 도구가 필요 없다(Linux는 Wayland/X11 프로토콜을 직접 쓴다 — 종전 `wl-paste`/`xclip` 의존 폐지).

**받는 쪽에는 승인 창이 뜬다** — 보낸 사람·경로 배지·파일 수·이름·크기를 보고 **승인/취소**한다.

![파일 수신 요청](img/manual/file-offer-modal.png)

| 표시 | 뜻 |
|---|---|
| `로컬(같은 망)` 배지 | 이 요청이 들어온 **경로 등급**(로컬 / 서버 경유 / 인터넷). 인터넷 경유는 지문 대조 전엔 파일이 막힌다 |
| *"서로 주고받은 메시지가 아직 없습니다"* | **아직 왕래가 없는 상대**의 파일은 자동 승인 설정이어도 **수동 승인으로 강등**된다 — 처음 보는 상대가 파일부터 던지는 것을 막는 규칙 |
| `1시간 ▾` + `자동 승인` | 이 상대를 **기간 한정 자동 승인**으로(설정 › 파일 › 승인 정책이 기본값) |
| `취소 (42초)` | 응답이 없으면 **시간 초과로 자동 취소**(기본 60초 · 설정 › 파일) |
| 안내 문구 | 승인해도 **격리함에 보관**된다 — 실행 가능한 파일로 만들려면 격리함에서 한 번 더 승인 |

- 보낸 쪽 말풍선은 `승인 대기 → 진행률(⏸ ▶ ✕) → 완료 — 평균 속도`로 바뀐다. 받는 쪽은 `완료 — 격리됨 · 위험 Data`처럼 **검사 등급**이 붙는다.
- 요청 한 번에 파일 **최대 5개**(설정) · 10GB급도 메모리에 올리지 않고 흐른다 · **끊겨도 이어받기**(같은 파일을 다시 보내면 받은 데까지 건너뛴다).
- 받은 파일은 **격리함**(툴바 방패)에 `.beepq` 봉인으로 있다. 이미지는 격리된 채로 **미리보기**만 볼 수 있고, 승인하면 보관함으로 나온다(macOS quarantine · Windows MotW 표식 유지 — 복원 뒤에도 OS가 "인터넷에서 온 파일"로 안다).

## 4. 그룹 대화

목록에서 상대를 **여러 명 선택**(⌘/Ctrl+클릭) → 우클릭 → **그룹 만들기**. 방이 하나 생기고 구성원 전원에게 초대가 간다(수락제).
그룹 행을 열면 **한 방에서 대화**하고, 파일도 방 단위로 보낸다(구성원별 승인 · 합산 배너 · 미왕래 구성원은 자동 승인이 아니라 수동).

![그룹 대화](img/manual/group-chat.png)

- 그룹 말풍선에는 **보낸 사람 이름**이 붙는다. 그룹 기록도 1:1과 같이 암호화 영속된다.
- 초대·구성원 편집(추가·제외·비소유자의 추천)은 그룹 행 우클릭 → 구성원.

### 5-3. 프로필 카드 · 키 지문 대조

![프로필 카드](img/manual/profile-card.png)

- 이메일·전화 등은 **상대가 공개한 항목만** 보인다(설정 › 프로필의 토글 — 기본 전부 비공개).

## 6. 트레이·메뉴바 상주

앱은 **트레이(Windows·Linux)/메뉴바(macOS)** 에 내 아바타 아이콘으로 상주한다. 아이콘 메뉴(Windows·Linux = 우클릭 · macOS = 클릭)는 **열기 · 설정… · 종료**다 — **열기**(또는 Windows·Linux 아이콘 클릭)로 창을 다시 부르고, 🆕 **설정…**(다음 릴리스)은 창을 앞으로 부르며 설정 화면을 바로 연다. 메뉴에 단축키 ⌘/Ctrl+, 가 함께 표시된다. **종료**는 여기서 한다(메뉴 › 종료도 같다).

![메뉴바 메뉴](img/manual/tray-menu.png)

| 설정(고급) | 동작 |
|---|---|
| **닫기 버튼 = 트레이로** | 켜면 X를 눌러도 종료되지 않고 트레이로 내려간다(기본 끔) |
| 🆕 **트레이에 있는 동안 작업표시줄/Dock에서 숨김**(v0.2.15 예정 · 기본 켬) | 트레이로 내려가면 작업표시줄/Dock에서 사라진다(macOS는 Dock 아이콘까지) · 끄면 최소화로 남는다 |
| **시스템 시작 시 자동 실행**(기본 켬) | OS 로그인 시 함께 뜬다 — 관리자 권한 없이 사용자 수준 등록 · 🆕 설치본·포터블·개발 빌드가 **각자 자리**를 갖는다(v0.2.13 — 한쪽을 끄면 다른 쪽이 꺼지던 줄다리기 해소) |

> Linux(GNOME Wayland)는 트레이 "열기"가 셸 토큰으로 진짜 포커스를 얻는다(v0.2.12). 확장(appindicator)이 없는 데스크톱은 [40 알려진 한계](40-known-limitations.md) §6.

## 7. 설정

**여는 법 세 가지** — ① 메인 창 **메뉴 › 설정** ② 단축키 **⌘/Ctrl+,**(어느 창에서나) ③ 🆕 **트레이(메뉴바) 아이콘 메뉴 › 설정…**(다음 릴리스 — 창이 트레이로 내려가 있어도 바로 열린다). 툴바 오른쪽 끝 아바타는 설정이 아니라 **프로필** 화면이다.
**바꾸는 즉시 적용**되고 조용해진 1초 뒤 저장된다.

> 🆕 **설정 화면 개편(다음 릴리스 · main 10-09)** — ⚠ 이 절의 캡처 4장은 **개편 전 화면**이다(새 캡처는 실기 뒤 교체).
>
> - **왼쪽 = 그룹 트리.** 여섯 그룹 아래 카테고리가 있다 — **일반**(시스템 · 프로필 · 사용자) · **대화**(대화 · 알림 · 그룹) ·
>   **모양**(모양 · 색 · 글꼴 · 목록) · **파일** · **네트워크**(네트워크 · 서버) · **고급**(고급 · IME).
>   그룹을 누르면 그 그룹의 설정이 전부, 카테고리를 누르면 그것만 보인다. 오른쪽 위 제목 = "그룹 › 카테고리".
> - **위 = 검색.** 단어를 여러 개 넣으면 **모두 들어간 것만**(AND) 남는다. 제목·설명·키 이름·그룹 이름을 다 본다.
>   한글은 **조합 중에도** 찾는다("ㅌ"·"테"만 쳐도 "테마"). 어느 언어 화면이든 한글·영어 둘 다 통한다.
>   **Enter** = 검색어 기록 · **↑/↓** = 지난 검색어 다시 불러오기.
> - **카드 하나 = 설정 하나.** 왼쪽 위 = 제목과 설명 · 오른쪽 위 = **키 이름**(⧉ 누르면 복사 — 설정 파일·CLI에서 쓰는 이름) ·
>   왼쪽 아래 = 컨트롤과 **[초기화]**(기본값과 다를 때만 보인다) · 오른쪽 아래 = "기본값: …".
> - **흐린 카드**는 다른 설정에 묶여 있다는 뜻이다 — 카드에 "“알림”을 켜면 쓸 수 있습니다"처럼 무엇을 먼저 켜야 하는지 적혀 있다.
> - **아래 줄 = [고급 설정] 스위치**(기본 꺼짐). 한 번 정하면 거의 손대지 않는 값(입력기 미세 조정 · 시간 상수 · 주기)은

### 7-1. 🆕 다중 기기 신원 — 내 PC들을 한 사용자로 (v0.2.15)

설정 › **사용자**. 내 PC가 둘 이상일 때 켠다(기본 꺼짐 = 단독 노드).

1. **다중 기기 신원** 스위치를 켜면 **핸들**(짧은 공개 이름)과 **페어링 암호**가 기본값으로 채워지고 바로 인증된다. 다른 PC에도 **같은 핸들·같은 암호**를 넣으면 끝이다.
2. 페어링 암호는 내 기기끼리만 아는 비밀이다. 서버로 가지 않고 이 PC에 봉인 저장된다. 생성 아이콘(🔄)은 **한 번 누르면 빨강으로 바뀌고 5초 안에 한 번 더** 눌러야 새 암호로 바뀐다. 눈 아이콘은 가림 토글.
3. 같은 값의 PC끼리는 **승인·지문 대조 없이** 서로를 "내 기기"로 인식한다. 목록 행에는 **보라색 인증 배지**, 프로필 카드에는 "내 기기 — 같은 사용자 키로 인증됨"이 뜬다. 파일도 승인 없이 받는다(격리·검사는 그대로).
4. 같은 LAN이면 서버 없이 되고, 다른 망이면 **설정 › 서버**를 관리형으로 켜 둔 상태에서 만난다(서버는 만남 지점만 — 내용·키는 보지 않는다). 처음 만나면 두 PC의 사용자 ID가 **먼저 만든 쪽으로 자동으로 합쳐진다**(30초 안팎).
5. **기기를 잃어버렸을 때** — "사용자 키 교체" 버튼(빨강 → 5초 안 재클릭). 이 PC만 남기고 다른 기기는 전부 폐기되니, 이어서 **페어링 암호를 바꾸고** 아직 가진 기기마다 새 암호를 넣어 다시 결합한다. 상대에게는 옛 ID가 새 ID로 자동으로 이어진다.

- 핸들은 라벨일 뿐 신원이 아니다 — 같은 핸들을 **다른 사용자 키**가 쓰면 목록에 ⚠ 표식이 붙는다(프로필 카드에서 ID로 구분).
- 값을 바꾸면 인증이 풀리고 다시 인증할 때까지 이 기능이 멈춘다. 암호를 바꿔도 사용자 ID는 그대로다.

### 7-2. 🆕 파일 고르기·저장하기 — 새 파일 대화상자 (다음 릴리스 · main 10-09)

파일이나 폴더를 고르는 곳(신원 키·설정·대화 기록 백업과 복원 · 프로필 사진 · 라이선스 파일)은 전부 **같은 대화상자**를 쓴다.
Windows·macOS·Linux 어디서나 **모양과 동작이 같다**. *(캡처 예정 — 실기 뒤)*

- **왼쪽 = 장소** — 홈 · 바탕 화면 · 문서 · 다운로드 · 드라이브(내 PC) · 최근 폴더.
- **위 = 경로 줄** — ← → ↑(상위) · 홈 버튼 · 경로를 눌러 직접 입력(`~`·환경 변수 사용 가능 · Enter = 이동).
- **가운데 = 목록** — 열 제목을 누르면 정렬(폴더 먼저 · 숫자는 자연 순) · 경계를 끌면 폭 조절 ·
  **더블클릭/Enter** = 폴더 들어가기·파일 확정 · **Backspace** = 상위 폴더 · 우클릭 = 열기 · 경로 복사 · 이름 복사 · 새로 고침.
- **아래 = 이름 · 형식** — 형식 상자에서 확장자 필터를 고른다(용도에 맞는 것이 기본 · 끝 줄 = 모든 파일) ·
  숨김 파일/점(.) 파일 표시 · [새 폴더].
- **Esc · [취소] · 창 닫기** = 아무것도 바뀌지 않는다. 다음에 열면 **직전에 있던 폴더**에서 시작한다(앱을 끄면 홈부터).

| 하는 일 | 대화상자 | 기본 형식 | 바뀐 점 |
|---|---|---|---|
| 신원 키 백업 | **저장** | 신원 키 (`*.key`) | 기본 이름 = `nexa-beep-identity-<지문>.key` · 이름을 바꿀 수 있다. 같은 이름이 있으면 **한 번 더 눌러야** 덮어쓴다(5초 안 · 예전엔 `-2`를 자동으로 붙였다) |
| 신원 키 복원 | 열기 | 신원 키 (`*.key`) | — |
| 설정 백업 | **저장** | 설정 백업 (`*.cfg`) | 신원 키 백업과 같다(이름 변경 · 덮어쓰기 확인) |
| 설정 복원 | 열기 | 설정 백업 (`*.cfg`) | — |
| 프로필 사진 | 열기 | 이미지 (png · jpg · gif · bmp · webp · ico) | 고른 뒤 **[적용]**을 눌러야 반영된다(종전과 같음) |
| 대화 기록 백업 | **폴더 고르기** | — | 고른 폴더 **안에** `nexa-beep-history-<지문>` 폴더를 만들어 담는다(종전과 같음) |
| 대화 기록 복원 | 열기 · **여러 개 선택** | 대화 기록 (`*.seg`) | 백업 폴더에 들어가 **⌘/Ctrl+A로 전부 고르면** 폴더째 복원(예전 "[이 폴더에서 복원]" 행 대신) · 일부만 골라도 된다(⌘/Ctrl·Shift+클릭) |
| 라이선스 파일 | 열기 | 라이선스 (`*.license`) | → 7-3 |

### 7-3. 🆕 라이선스 (다음 릴리스 · main 10-09)

**도움말 › 라이선스…**. **비상업적 사용은 무료**이고 라이선스 파일이 필요 없다(상태 = "무료 — 비상업적 사용"). 상업적으로 쓰려면 라이선스를 받는다.
앱은 라이선스 확인을 위해 **어디에도 접속하지 않는다**(파일과 서명만 본다). *(캡처 예정 — 실기 뒤)*

1. 창 가운데 **이름 · 이메일**을 넣고 **[요청 코드 복사]** → 한 줄 코드가 클립보드에 들어간다(이 PC의 기기 코드는 해시만 담긴다).
   창에 적힌 이메일 주소(누르면 복사)로 그 코드를 보낸다.
2. 받은 `nexa-beep.license` 파일을 저장하고 **[라이선스 파일 열기…]** → 7-2 대화상자에서 고른다.
   검증을 통과한 파일만 설치되고(원본은 그대로), 위 상태 띠가 **"정식 라이선스 — pro"** 처럼 바뀐다.
3. 다른 PC용 · 다른 제품용 · 손상된 파일은 설치하지 않고 이유를 보여 준다(그대로 무료로 동작).
   **[제거]** = 이 사용자의 라이선스 파일 삭제(관리자가 둔 기기 공용 라이선스가 있으면 그것으로 돌아간다).

- **설정 › 고급 › 라이선스**(읽기 전용 정보 4행) — 상태 · 라이선스 ID · 파일 위치 · 기기 코드를 창을 열지 않고 본다.
- 터미널: `nexa-beep --license status` · `request [이름 [이메일]]` · `install <파일>` · `remove` · `path`
  (종료 코드 0 = 성공 · 1 = 거부/실패 · 2 = 사용법).
- 파일 자리 = 데이터 폴더의 `license/`(포터블 = 실행 파일 옆 `data/license/`) → 없으면 기기 공용
  (Windows `%ProgramData%\nexa\nexa-beep` · macOS `/Library/Application Support/nexa/nexa-beep` · Linux `/etc/nexa/nexa-beep`).

## 9. 문제 해결

| 증상 | 확인 |
|---|---|
| 상대가 목록에 없다 | 같은 LAN인가(게스트 Wi-Fi·VLAN은 멀티캐스트를 막는다) → 툴바 **재발견** → 필터 바 `On` 칩이 온라인만 보고 있지 않은가 → 그래도 없으면 **⌘/Ctrl+K로 IP 직접 추가**(같은 망) 또는 **서버 Managed**(다른 망) |
| 내가 상대에게 안 보인다 | 방화벽이 UDP 47100(발견)·TCP 47200(세션)을 막는지 · 상태바 `수신 :포트` 확인 · 두 인스턴스가 한 PC에서 같은 포트를 물지 않았는지(`--port`) |
| 붙여넣기(⌘/Ctrl+V)가 안 된다 | v0.2.14부터 외부 도구 없이 동작한다. 그래도 안 되면 클립보드에 **이미지**가 있는지(텍스트는 글로 붙는다) · Linux X11/KDE는 실기 중 |
| 파일이 `승인 대기`에서 멈춘다 | 상대 화면의 승인 창을 기다리는 중 — 60초 지나면 자동 취소 · **아직 왕래가 없는 상대**는 자동 승인이어도 수동으로 강등된다(메시지를 한 번 주고받으면 풀린다) |
| 재시작하니 상대가 나를 모른다 | `identity.key`가 바뀌었다(임시 폴더에 두었거나 지웠다) — `--whoami`의 지문이 전과 같은지 · 백업 복원 |
| 트레이에서 "열기"를 눌러도 창이 안 뜬다(Linux) | GNOME은 appindicator 확장 필요 · [40 §6](40-known-limitations.md) |

## 10. 부록 — 이 캡처를 다시 찍는 법(앱 페이지·릴리스 노트용)

같은 PC에서 신원 두 개를 띄우고 **창 ID로** 찍었다(겹친 창에 영향받지 않는다). 절차는 [26 §3-4](26-run-and-manual-test.md)의 다신원 원리와 같다.

```bash
# ① 신원 폴더 2개(실행 파일 옆 data/ = 그 인스턴스의 신원·설정)
for id in E F; do mkdir -p /tmp/cap/id$id/data && cp target/release/{nexa-beep,nbeep-imgdec} /tmp/cap/id$id/; done
printf '_schema=1\nchat.window_mode=separate\nprofile.display_name=Alice\nui.language=ko\nui.theme=light\nxfer.approval=auto\napp.autostart=off\n' > /tmp/cap/idE/data/settings.cfg
printf '_schema=1\nchat.window_mode=single\nprofile.display_name=Bob\nui.language=ko\nui.theme=dark\nxfer.approval=auto\napp.autostart=off\n'   > /tmp/cap/idF/data/settings.cfg
(cd /tmp/cap/idE && ./nexa-beep --window --live --port 47221 &) ; (cd /tmp/cap/idF && ./nexa-beep --window --live --port 47222 &)
# ② macOS: 창 ID 목록(CGWindowList) → screencapture -l <id>  · 조작은 cliclick(클릭) + 클립보드 붙여넣기(IME 우회) + System Events의 Return
screencapture -x -o -l <windowID> out.png
```

- 텍스트는 `pbcopy` → ⌘V로 넣는다(합성 키 입력은 한글 IME를 타 깨진다). Return은 `osascript -e 'tell application "System Events" to keystroke return'`.
