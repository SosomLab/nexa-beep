## (Win · main) 메인 창 한눈 식별 — 로컬/서버 경로 + 사용자(핸들) 신원 상태(`eac6c94` · 사용자 요청 "Local인지 Relay/Contents 서버 연결인지 · UserId(Handle) 설정이 됐는지 가시성 높은 식별")

**공백** — "인증됨"은 이 PC 안의 로컬 판정(KP 파생 + `user.key` 열림/생성)뿐. 다른 기기와 **실제로 묶였는지**(형제 세션·키 병합·기기 목록), 지금 **로컬인지 서버에 붙었는지**가 메인 창 어디에도 없었다. 2-PC 실기 "같은 값인데 ID가 다름"이 정확히 이 공백 — 양쪽 다 "✓ 인증됨"인데 결합은 안 된 상태를 구분할 수 없었다. 첫 설계(설정 노트+`--whoami`)는 사용자 정정("메인 창에서 한눈에")으로 표시 자리를 옮겼다.

**판정(순수 · `userident.rs` · 회귀 1종)** — 한 함수가 정하고 다섯 자리가 같은 값을 읽는다.

| 축 | 값 | 근거(전부 기존 상태값) |
|---|---|---|
| 서버 경로 `ServerLink` | Local(Unmanaged) / Held(미검증·보류·실패·핀 정지) / Reconnecting(검증됨·재접속 대기) / Connected(kind) | `server_target`·`relay.is_alive`·`server.verified`·`relay_hold`·`relay_test_failed`·백오프 — `server_note_texts`와 같은 우선순위 |
| 사용자 단계 `UserLevel` | Off → Blocked → Local(인증 ✓·나 하나·통로 없음) → Seeking(통로 열림·형제 0) → Paired(형제 ≥1) | `user.enabled`·`UserState::active`·`siblings`(세션)·`my_devices()`(trust.seg 기록 — 오프라인이어도 유지) |

**표시 자리(메인 창 · 사용자 확정 = 세 자리 전부)**
- **툴바 연결 아이콘** — 종전 "릴레이 접속 중일 때만 표시" → **항상 표시**: LAN만 = 집 아이콘 흐림 · 서버 = 경유점(열림 accent / 보류·재접속 흐림 — `StatusMask.dim` 신설). 툴팁 = 상태별 4종(`로컬(LAN)만 · 서버 없음` / `서버 설정됨 · 미검증 — [테스트]` / `검증됨 · 재접속 대기 — 주소` / `{릴레이|컨텐츠|등록형} 서버 연결됨 — 주소`). 종류는 `net.server.type` 표기(auto = 릴레이 — 타입 협상 축은 미구현이라 표기만).
- **툴바 아바타 링**(`Avatar.ring` 신설 · 원 바깥 2px · 보더와 별개) — 인증 = "내 기기" 보라(`OWN_DEVICE_COLOR`) · 값 문제·실패 = 호박 · 암호 불일치 의심 = 호박 · 꺼짐 = 없음. 툴팁 = `사용자 핸들 · ID · 내 기기 N대(M 접속 중)` + 진단 꼬리.
- **상태바 칩 2개**(포트 왼쪽 · 오른쪽부터 `[경로][사용자]`) — `LAN` / `서버: 미검증` / `릴레이: 재접속 대기` / `릴레이 ✓` · `단독` / `사용자: 미인증` / `kiros33 · 1대`. 색 = 통로 열림·인증 = accent 옅게 · 보류·미인증·불일치 = 경고 · 그 외 흐림. 페인트는 캐시(`user_glance`)만 읽는다 — windows 가변 차용 구간이라 self 메서드 호출 불가 → 칩 문구는 페인트 진입 전에 계산.
