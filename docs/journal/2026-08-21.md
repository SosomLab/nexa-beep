## ② 오프라인 큐(M4-6 · C-3 · FR-M-3) — `221bde6`

**발각된 사전 구멍** — 세션 없는 발신은 풍선만 남고 **조용히 유실**됐다(send
합류점의 `if let Some(conv)` fall-through — 전송도 기록도 없음). 큐가 이 구멍을
메운다.

- 세션 없음 = 상대별 보관(상한 200·오래된 것부터) + 풍선 **대기 막대**(점 계열과
  모양 분리 — 색맹 안전) + 상태바에 **한계 명시**("내 PC가 켜져 있고 상대가
  나타나면") + 즉시 연결 시도.
- 영속 = `data/pending/{short}.seg`(**SEAL_PENDING** 봉인 · 원자적 쓰기) · 부팅
  복원 = 핀 매핑 + 대기 풍선 재생 + 재연결 후보 등록.
- flush = 세션 성립 합류점(Outbound·Inbound — `flush_group_sends` 옆): fresh seq
  발신 · `resolve_queued`로 풍선 해소 · **세션 급사 시 잔여 도로 대기**(유실 금지).
- 발견 Appeared 훅 = `reconnect.entry().or_insert((0,0))` — **or_insert가 요점**
  (Appeared는 비컨마다 온다 · 덮으면 1.5초 재시도 폭주).
- 회귀: 코덱 왕복+꼬리 손상 fail-soft · resolve_queued.

- **실측**: imgdec raw 왕복 **비트 동일**(2x2 → PNG 86B → 재디코드 픽셀 일치) ·
