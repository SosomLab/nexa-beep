## 소개글(Bio) 입력·표시 다듬기 + 남은 화면 i18n (사용자 실기 연속 · 10커밋)

사용자가 프로필 소개글(Bio)을 실기하며 요청·버그를 연달아 냈고, 남아 있던
화면 한글 고정도 마저 i18n했다. 전부 그때그때 커밋·push·재기동으로 확인.

**Bio 입력란 (M3-17 후속)**
- **고정 3줄 표시 + 내부 스크롤로 확정**(사용자 확정): 처음엔 "1줄→Enter로
  자동 성장 + 창 크기 성장"으로 갔다가, 이어 "고정 헤더 + 스크롤 중간영역 +
  고정 하단 버튼"의 **큰 재설계는 취소**하고(이 렌더러 `DrawCtx`에 클립 API가
  없어 불투명 덮어그리기+좌표 변환이 필요 = **M3-24로 등록**), **최대 3줄 표시
  + 초과분 스크롤**로 최종 확정. 창 고정 770.
- **마우스 휠 스크롤**(종전 미동작) → 멀티라인 vscroll에 사용자-스크롤 플래그
  (`ml_user_scrolled`) 추가: 휠/바로 스크롤 중엔 캐럿을 안 따라가고, 타이핑/
  방향키/클릭 시 캐럿 추종 재개.
- **대화 입력창과 동일한 스크롤바**(`ScrollBars`) 멀티라인 TextBox에 통합 —
  상하+좌우 오버레이·자동 숨김·썸 드래그·휠/HWheel. 콘텐츠 크기(최대 줄 폭·
  총 높이)를 paint가 실측·캐시 → on_event(폰트 못 잼)가 계산.
- ★**가로 스크롤 끝 ~2글자 가림 수정**(실기): 스크롤바는 뷰포트를 `vp.w`로
  보는데 실제 텍스트 뷰포트는 좌우 여백 `s(20)`을 뺀 값 → 최대 이동이 그만큼
  짧았다. content_w에 `s(20)`을 더해 paint의 max_hs와 일치.
- ★**재시작 시 개행 소실 수정**(실기 · nexa-conf): serialize가 값 속 개행을
  **공백으로 치환**해 영속 시 소개글 줄바꿈이 사라졌다(인메모리는 정상) →
  **줄 분리자 U+2028/2029로 왕복 보존**(parse가 역치환). ★`\n`→`\\n` 이스케이프는
  Windows 경로(`C:\new`→`\n`)와 충돌해 안 씀 — 경로 왕복 회귀 추가.
- ★**붙여넣기 개행 소실 수정**(실기): `paste`가 단일 행 전제로 개행·제어를
  공백 하나로 접었다 → 멀티라인은 개행 **보존**(`\r\n`/`\r`→`\n`·그 외 제어만
  접음). 단일 행은 종전대로. 회귀 추가.
- **목록 소개글 말줄임(…)**: 목록 2번째 줄이 폭을 넘으면 `fit_ellipsis`로 잘라
