## 설정 화면 커스텀 컨트롤 전면 교체 + 모달 파일 선택 + 타입어헤드 확정판 (feat/m3-settings-controls)

- **설정 화면 재작성**(사용자 확정 — 자체 렌더 전면 교체): 검색=`TextBox` · 사이드바=`TreeView`
  (검색 중 매치 카테고리+"(N)") · 택일=`Combo` 드롭다운 · on/off=**`Checkbox`**(신설
  `SettingKind::Toggle` — 공백/특수문자) · 글꼴 영역=`TextBox`+`Combo`. 열린 콤보 **모달 캡처**
  +맨 위 재도색. `take_changes` 계약 유지(bin 무변경). 테스트 8종 재작성.
- **모달 파일 선택 창**(사용자 확정 — 인라인 오버레이 → 별도 창): 갤러리 Choose…를
  `take_choose_request`로 올려 bin이 `Role::Picker` 창을 연다. 내용은 **ChoosePicker 어댑터**
  (FilePicker · HOME 단일 파일)를 TreeView로 렌더 — 항목 클릭=값 반영·닫힘, Esc=취소.
  인라인 오버레이 모드(`set_picker`)도 공존(어댑터 주입 여부로 선택).
- **타입어헤드 확정판**: ① Space 유실 수정(bin이 `Named(Space)`를 Char `' '`로 라우팅 —
  대화 입력 직타 스페이스 유실도 함께 해결) ② **반복 키 자동 순환 제거**(순환은 ↑↓ 전용)
  ③ ↑↓ 순환 중 touch로 타임아웃 리셋 ④ HUD 즉시 갱신('bo'의 o 지연 표시 수정)
  ⑤ tick이 조합 텍스트(preedit)도 초기화(한글 HUD 미소멸 수정).
- **버튼 이미지 정확한 원인 수정**: 갤러리 set_scale가 버튼 3종에 배율 미전파(Retina에서
  절반 크기). 전파 추가 + 선행 아이콘 `LEADING_ICON=13` 단일 원천(콤보·트리·버튼 — 드리프트 방지).
- 워크스페이스 233 green · clippy·fmt clean.

## 커스텀 컨트롤 툴킷 다듬기 + 오버레이 스크롤바 + Choose 어댑터 + 브랜딩 아이콘 (feat/m3-controls-polish)

사용자와의 긴 대화형 반복(수십 건 미세 조정)으로 커스텀 컨트롤 툴킷을 실사용 수준으로 다듬은
브랜치. 17커밋. **워크스페이스 218테스트 green**(core 91·ui 97·gfx 5·기타).

**컨트롤 치수·시각 정리**
- 체크박스·라디오 글리프 12px 동일 · 입력/콤보/텍스트박스/버튼 높이 통일 · 포커스 링 2px·50% 반투명.
- 콤보/Choose/트리/버튼 아이콘 **13 정사각**(텍스트 세로 중앙) · 버튼은 높이 채움 · 셰브론 좌우 짧게(w/5)
  ·회색(text_dim)·우측 여백 2px · ⇕ 2px 근접 · 트리 ›/∨ 동일 세트.

**오버레이 스크롤바**(`controls::ScrollBars` · 재사용 컴포넌트)
- macOS식: 스크롤 전 숨김 → 스크롤=표시(1) → 바 호버=두껍게(2) → 무활동 tick으로 페이드(0). 항상 반투명.
- 갤러리 + TreeView + TreeGrid 내부 스크롤(행/열 넘침) 적용.

**Choose(=구 ExtendedCombo) 찾기 어댑터**(Adapter 패턴)
- `ChoosePicker` 트레이트(title/items) — 어떤 화면도 꽂을 수 있음. 인라인 오버레이로 후보 목록 표시,
  선택 시 값 반영. bin `FilePicker`(HOME 단일 파일) 샘플 주입. ★ 목록 선택 시 박스 텍스트 미갱신 버그 수정.

**이미지 아이콘**(gfx `IconImage` RGBA · 투명 배경)
- `blend_image`/`blend_image_scaled`(스케일·클립) + `DrawCtx::image(_scaled)` · `image_fit_contain/cover`.
- ComboItem/TreeNode/Button/TextBox에 선행 이미지(글리프 폴백). 큰 이미지 자동 축소.
- **Button 컨트롤**(이미지+텍스트/이미지만/이미지 버튼 Cover·Contain). TreeView/TreeGrid 행 이미지 + 이미지판 우측 병치.
- 갤러리 이미지 데모를 **브랜딩 이미지**로(brand-64.rgba 임베드 · 런타임 디코더 불요).

**i18n·타입어헤드·도움말**
- TextBox placeholder 고정 + Beam 캐럿 별도 렌더 · 대화창 빈 입력 Beam.
- 타입어헤드 **IME 실시간 매칭**(한글 조합 즉시 · preedit) · 유효시간 2000ms(설정) · HUD 위치 3×3(설정) ·
  공백/특수문자 포함(설정) · 유효시간 경과 tick 초기화(조합 텍스트 포함) · ↑/↓ 순환(역방향 · 언어 중립).
- 도움말 "?" 세로 중앙·배지 밖/포커스 이동 시 자동 숨김·툴팁 상하 여백 균등.
- 트리/트리그리드 외곽 Border(두께 f32 0.5px 가능·색·투명도 `BorderSpec`) · 그리드 헤더 세로 중앙.

**브랜딩 아이콘**(`packaging/branding/`)
- Nexa 계열 풀블리드 라운드 스퀘어 + 말풍선 + 비콘 파동("beep") · icon.svg(SSOT) → PNG 1024/256/64 + .ico.

**공통 상속 원리**(사용자 "모든 컨트롤이 상속받아 확장") — `Control`+`ControlBase`(포커스 링·활성·도움말),
`ComboControl`(Combo/Choose), `TreeControl`(TreeView/TreeGrid): 트레이트 계층 + 공유 상태 컴포지션 + 기본 메서드 전파.

⏳ **미완료(후속)**: Choose "Choose…" **별도 모달 창**(현재 인라인 오버레이) · 설정의 on/off 항목을 실제
Checkbox 위젯으로(현재 콤보) · 컨트롤을 **설정 화면에 정식 통합** · 런타임 창 아이콘 연결(PNG 디코더).
