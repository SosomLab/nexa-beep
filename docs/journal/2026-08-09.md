## 전수 검증 — "코드는 있는데 동작을 본 적 없는 기능" 점검 (사용자 요청)

요청: *"지금까지 개발된 내용 중 **직접적으로 확인되지 않은 기능**을 모두 정리해 달라. 동작을 확인하고 완료 처리 및 문서 최신화를 하고 싶다."*

### 🔴 점검을 시작하자마자 나온 것 — CI가 red였다

기능을 세기 전에 CI 상태부터 봤는데 **main에서 3회 연속 실패** 중이었다. `main은 항상 green`([18 §3](../18-build-and-test.md))이 규약인데 깨진 채로 "완료 처리"를 할 수는 없어 이걸 먼저 잡았다.

원인은 **rustdoc `-D warnings` 6건**이고 전부 **문서 주석 링크**였다 — 코드 동작과 무관하다:

| 위치 | 오류 | 원인 |
|---|---|---|
| `core/i18n.rs` ×2 | public documentation links to private item | `Msg::row`가 private인데 public 문서에서 링크 |
| `ui/settings.rs` ×2 | unresolved link / redundant target | `[`TextBox`](글꼴명)` — **링크 문법 오용**(괄호 안이 링크 대상이 아니라 설명 텍스트였다) |
| `ui/controls/combo.rs`·`tree.rs` | redundant explicit link target | `[`Control`](super::Control)` → `[`super::Control`]` |

lint 잡만 실패했고 build·test는 통과하고 있었다. 그래서 **기능은 멀쩡한데 게이트만 막혀 있던 상태**였다.

### 게이트 재확인

`fmt` ✅ · `clippy` **0건** · **테스트 243 통과** · `rustdoc` ✅.

### ★ 실증 8건 — 직접 실행해서 눈으로 봤다

| # | 기능 | 방법 | 결과 |
|:--:|---|---|---|
| 1 | 실물 멀티캐스트 발견 | 로컬 2노드 `--discover-probe` | **양방향** — 서로 `Hello`·`Announce` 관측 |
| 2 | 종단 왕복 | `--live-echo` 2노드 | `SERVER recv` → `CLIENT got reply`, **한글** |
| 3 | 정상 종료 | `SIGTERM`/`SIGINT` | **0.09초 / 0.11초** |
| 4 | ★ **GOODBYE 발신** | 관찰 노드가 이탈을 관측 | **`kind=Goodbye` 4회 수신** |
| 5 | 수동 엔드포인트 | `--serve`↔`--connect` | `peer=…(지문 확정)` |

**가장 값진 것은 4번이다.** 어제 R-16으로 *"FR-D-8의 절반(GOODBYE)이 구조적으로 비어 있다"* 고 등록했는데, 종료 포트가 들어온 뒤 **관찰 노드가 실제로 `Goodbye`를 받는 것**을 확인했다. 설계에서 비었다고 적은 자리가 실제로 채워진 것을 눈으로 본 셈이다.

### 미확인을 성격별로 갈랐다 — "왜 아직 못 봤나"가 다르기 때문

- 🖥 **육안(GUI) 필요 7건** — 피어 목록·신뢰 배지 3종 · 다중 창(M3-12) · 설정 화면(M3-11) · 컨트롤 갤러리 · 이미지 아이콘 · i18n 전환 · 고DPI/한글 IME. **헤드리스로 대행할 수 없다.**
- 🔬 **시나리오 재현 필요 5건** — U-P1 클론 탐지·U-P2 자기 `PeerId` 거부(키 파일을 실제로 복제한 환경이 필요한데 매 실행마다 키를 새로 만든다) · `name_conflict` · 백프레셔·프레임 상한 · 중복 제거.
  - ⚠️ 그중 **SAS 60자리는 성격이 다르다** — 구현·단위 테스트는 됐는데 **CLI에도 GUI에도 출력 지점이 없다.** 즉 "확인 못 한" 게 아니라 **아직 사용자에게 보여줄 수단이 없는 것**이다(M3-6).
- ⏸ **실기 필요** — D-8b 타이밍(2대+) · 클라이언트 격리 AP S4(R-2) · Windows/Linux 실기 · 24h 누수 · 유휴 RSS 재실측(R-8 잔여).
