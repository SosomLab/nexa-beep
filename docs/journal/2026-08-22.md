## 문서 구성(구현에서 뽑은 것만)

- **mermaid 3종** — ① 전체 시퀀스(등록→랑데부→사다리→종단 Noise) ② RID 유도 흐름
  ③ 사다리 판정 플로차트.
- **§2 식별자 셋** — `PeerId`(64hex = X25519 공개키 32B) / RID 16B / 채널 u32 / 서버 핀.
  ★ **왜 8자리 축약이 아니라 64hex인가** = RID 계산에 공개키 원본 32B가 필요한데 축약본은
  키를 복원할 수 없다(`parse_peer_hex`가 길이 64·hex 아니면 즉시 None — fail-closed).
- **§3 RID** — `SHA-256("nbeep-rid-v1" ‖ pk ‖ epoch_day_be)[..16]` · UTC 일 회전 ·
  **어제·오늘·내일 3개 등록**(시계 오차) · 여는 쪽은 오늘→어제→내일 순 · `MAX_RIDS=8`.
  ★ 핵심 성질 = **"이미 아는 사람만 계산 가능" → 릴레이는 새로운 만남을 주선하지 않는다.**
- **§4~§5 등록·랑데부** — 서버와도 Noise → 서버 정적 키 = TOFU 핀(`server.pin` `v1 <addr> <64hex>`)
  · `PinMismatch`는 조용한 재핀 없이 실패 · `RegisterOk`의 udp_token/udp_port/observed 용도 ·
  `OpenResult.status` 0/1/2/255 해석표.
  ★ **순서 규약 2건** = 여는 쪽은 프로브가 `Open`보다 **먼저**, 받는 쪽은 프로브가 `Accept`보다
  **먼저** — 안 지키면 관측 엔드포인트가 상대에게 안 실려 홀펀칭 재료가 사라진다.
- **§6 사다리** — 1단 홀펀칭(성공 기준 = UDP 개통이 아니라 **종단 핸드셰이크까지**) → 2단 릴레이.
  펀치 소켓은 **시도마다 새로**(NAT 매핑은 로컬포트·목적지 쌍에 붙는다) · 받는 쪽은
  **첫 프레임이 온 링크**로 단을 고르고 `PrefixedLink`가 그 프레임을 핸드셰이크에 되살린다.
- **§7 종단 Noise** — 서버가 자기 계층을 벗겨도 A↔B 암호문만 남는 이중 봉투 그림 ·
  ★ `finish_via`의 `session.peer() != dst → WrongPeer` = **RID는 힌트, 근거는 암호학적 증거** ·
  `PathTaken`(표시) vs `PathClass`(정책)를 분리하고 **주소 미상 = Remote(fail-closed)**.
- **§8 데이터 평면** — `RelayLink: Link` 한 줄로 위층 무변경(DR-21) · `RELAY_CHUNK` 32KiB
  투명 분할·`fin` 조립.
- **§9~§10** — 서버가 보는 것/못 보는 것 표 · 옵트인 roster(공개키만 · 이름은 종단이 나른다) ·

  채널 64 · RID 8 · 핸드셰이크 10초).

## ① X-UDP-e 원격 사다리 — `connect_via`/`accept_via` (nbeep-relay)

- **여는 쪽** `connect_via`: 랑데부(에폭 RID 오늘→어제→내일) → **홀펀칭 시도** →
  실패 = **릴레이 폴백**. 각 단이 독립 핸드셰이크라 단 사이 오염이 없다.
  인증 키 ≠ 지정 지문 = `WrongPeer` 폐기(RID는 힌트 — 근거는 암호학적 증거).
- **받는 쪽** `accept_via`: 펀치를 병행하며 **첫 프레임이 온 링크**로 종단 수락 —
  여는 쪽이 어느 단을 골랐든 따라간다(`PrefixedLink`가 첫 프레임을 재생).
- **구조 변경 = 지연 수락** — 액터의 자동 Accept를 소비자 호출로 미뤘다. 이유:
  수락 **전에** UDP 프로브를 마쳐야 서버 OpenResult에 내 신선한 관측 엔드포인트가
  실린다(프로토콜 순서가 자연히 보장 — Open 전 프로브/수락 전 프로브). **펀치
  소켓 = 관측 소켓, 시도마다 신선하게** — 소켓 공유의 recv 경합(두 링크가 서로의
  데이터그램을 훔침)을 원천 차단. 서버는 미수락 CloseCh를 열기 거절(2)로 즉시
  알린다(여는 쪽 타임아웃 대기 제거).
- 부수: `pinfile`(서버 TOFU 핀 영속 — v1 텍스트·원자적 교체·손상 줄 = 핀 부재) ·
