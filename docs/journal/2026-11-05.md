### 사용자 질문 "nexa-dir3에서 어제 한 winit 보완이 여기에도 반영됐나"

- 대상 = nexa-dir3 `cd17f2d`(11-04) **GAP-042 winit 0.30.13 `TaskbarCreated` 교착 우회** · 자족 이식 문서 = nexa-dir3 `docs/27-winit-taskbar-deadlock.md` §4.

### 결함(요지 · 상세 = dir3 docs/27 §2)

작업 표시줄 재생성(RDP 재접속 · explorer 재시작) 브로드캐스트 `TaskbarCreated`를 winit 0.30.13이 **창 상태 Mutex 가드를 쥔 채** `ITaskbarList::AddTab`(`SendMessageW` 동기 대기)으로 처리 → 대기 중 테마 변경 후처리 `SetWindowPos` → `WM_WINDOWPOSCHANGING`이 같은 가드 재진입 → 영구 "응답 없음". 상류 수정 PR #4563은 0.31에만 · 0.30.13이 0.30 마지막.
