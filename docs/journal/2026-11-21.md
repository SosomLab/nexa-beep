## 교훈

- **mac 점검은 "OS가 다르다"보다 "시험 환경 가정이 다르다"가 먼저 걸렸다** — 언어(선호 언어 목록) · 첫 exec 검사 · 메인 스레드 동기 대기. Linux 초록이 mac 초록을 보장하지 않는다.
- **측정 도구가 빈 값을 0으로 읽으면 PASS가 된다** — 판정은 값이 없을 때 실패해야 한다.
- **공용 lib를 치환으로 고친 뒤에는 소싱해서 결과(변수·함수)를 확인한다** — `bash -n`은 내용이 사라진 것을 못 잡는다.
- **"멈춤"은 바쁨이 아닐 수 있다** — sample의 메인 스레드가 런루프 대기였다. 창 없는 앱은 OS 전원 정책(App Nap) 대상이다.
- **로컬 clippy와 CI clippy는 판이 다를 수 있다** — 코드 push 뒤에는 CI run 결과까지 본다.
