## 메시지별 전달/읽음 표시 — 완전 독립 축 (main · 사용자 요청)

§5 원안(수동 Acknowledged·읽음 안 만듦)을 사용자 확정으로 **개정**: 읽음 =
창 열어 보면 자동, 전달과 독립.
- `AckKind::Acknowledged → Read`(자동) · ChatLine seq·delivered·read(독립 2불).
- 발신자: Delivered = 그 seq 하나 / **Read = up-to**(seq 이하 전부 · 창 열면
  보이는 것 다 읽힘) · 두 축 독립.
- 수신 자동 읽음: activate(창 열기)+note_incoming(보이는 중 수신) → send_read_ack
  · 게이트 = `chat.send_read`(기본 on·수신자 제어) AND 검증(프라이버시·전달과
  같은 결·독립) · last_recv_seq up-to.
- ★ 표시 추천·구현 = **자체 렌더 점 마크**(글자·이미지 아님): 전달 = 점 1(dim)·
  읽음 = 점 2(강조) · **색맹 안전 이중 부호화**(모양+색 · M3-19 교훈)·에셋 0·
  내 메시지만. 설정 `chat.send_read`(4-lang). **675 green**.
