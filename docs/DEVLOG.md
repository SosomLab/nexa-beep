- **ADR-0003 전송 계층 추상화 제안(D-9 — Proposed)**: [09 ADR-0003](09-adr-0003-transport-abstraction.md) — DR-8의 "2모드 전제"를 **4계층 경계**(App / Session / Transport / Link)로 구체화. 핵심 인식 = 나중에 전송을 끼워 넣을 때 발목을 잡는 건 전송 코드가 아니라 **상위로 새어 나간 전송 세부사항**(IP가 App 자료구조에 있음 · 연결=대화로 묶임 · 암호화가 전송 안에 있음 · 오프라인 큐가 로컬 전제)이라는 것. 타입 4종(`PeerId`/`Locator`/`Link`/`Session`)과 **누수 금지 규칙 5개**(모듈 가시성으로 강제)를 정의. **부수 효과가 더 컸다** — `InMemoryTransport`로 세션·대화·그룹·무해화를 **네트워크 없이 단위 테스트**할 수 있고, 이건 4타깃 CI에서 멀티캐스트를 쏠 수 없다는 현실을 생각하면 미래 투자가 아니라 **당장 필요한 것**. 릴레이가 보는 것/못 보는 것을 표로 명시(**메타데이터는 본다** — 숨기지 않음). 상세 [journal/2026-08-08.md](journal/2026-08-08.md).
