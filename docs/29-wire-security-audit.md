# 29 · 와이어 보안 점검 기준 — "봉투를 열어보거나 스니핑하면 무엇이 보이는가"

> **성격: 검증 기준 + 실측 절차.** [10 §0 관통 원리](10-decision-record.md)("어떤 계층도 자기 일에 필요한 만큼만 본다")를 **주장이 아니라 측정 가능한 항목**으로 바꾼 문서다.
> 작성 2026-08-09 · 🔴 **실측 결과 R-18·R-19 신규** · 관련 [08 ADR-0002](08-adr-0002-discovery-transport.md) · [17 ADR-0005](17-adr-0005-history-at-rest.md) · [21 신원 규격](21-identity-spec.md) · [22 ADR-0008](22-adr-0008-profile-disclosure.md)

---

## 1. 두 가지 공격 시도를 나눈다

| | **① 봉투를 열어본다** | **② 패킷을 스니핑한다** |
|---|---|---|
| 누가 | **경로 위의 참여자** — 릴레이(v2)·중계 장비·저장 매체를 주운 사람 | **같은 브로드캐스트 도메인의 누구나** — 앱을 쓰지 않아도 된다 |
| 무엇을 노리나 | 계층이 **자기 몫보다 많이 보는가** | 와이어에 **평문으로 흐르는 것** |
| 우리 방어 | 계층별 봉투/내용 분리(관통 원리) | E2E(Noise) + **평문 구간의 내용물 통제** |
| ⚠️ 핵심 | 봉투가 **너무 크면** 분리가 무의미 | **발견 패킷은 의도적으로 평문**이다 — 그래서 *"무엇이 실리면 안 되는가"* 가 전부다 |

> ★ **이 문서의 초점은 ②의 평문 구간이다.** 세션은 AEAD로 닫혀 있지만 **발견 패킷은 설계상 평문·무인증**([08 §2](08-adr-0002-discovery-transport.md))이고, 거기 무엇이 실리는지가 곧 우리가 LAN 전체에 공짜로 주는 정보다.

## 3. 🔴 실측이 드러낸 것 — 오늘 캡처한 진짜 패킷

**절차**([§4](#4-실측-절차)) — 앱을 `홍길동-MacBook` 이름으로 띄우고 멀티캐스트 그룹에 조인해 88바이트 ANNOUNCE 3개를 받았다.

```
--- 88B from 172.30.55.87 ---
4e 58 42 50 01 02 00 00 1e 43 f6 7f 7b ed 2a 58 …(공개키 32B)… 66
e2 ac  00 00 00 00 00 00 00 01  00 00 00 02  d4 37 …(instance 16B)… 99
11  ed 99 8d ea b8 b8 eb 8f 99 2d 4d 61 63 42 6f 6f 6b
ASCII: NXBP..........................................................-MacBook
```

| 필드 | 실측값 | 판정 |
|---|---|---|
| `static_pubkey` 32B | `1e43f67f…` — **3개 패킷 모두 동일** | 🔴 **W-6 미달** |
| `tcp_port` | `e2ac` = 58028 | ✅ 연결에 필요 |
| `epoch` | `1` — **실시각이 아니라 카운터** | ✅ 가동 시간 미노출 |
| `seq` | `2` → `3` 증가 | ✅ 재생 억제용 |
| `instance` 16B | `d437df46…` — 프로세스마다 바뀜 | ✅ 추적자 아님 |
| `name` 17B | **`홍길동-MacBook` UTF-8 평문** | 🔴 **W-5 미달** |

### 🔴 R-19 — 표시 이름이 평문으로 브로드캐스트된다

FR-D-9는 표시 이름 기본값을 **호스트명 기반**으로 둔다. macOS 호스트명은 대개 **`{사용자 실명}의 MacBook Pro`** 이고 Windows도 사용자명을 포함하는 경우가 많다.

⇒ **앱을 켜는 순간 LAN 전체에 실명이 주기적으로 방송된다.** 카페·공항·사무실에서 앱을 쓰지 않는 사람도 받는다.

이건 [22 ADR-0008](22-adr-0008-profile-disclosure.md)이 *"브로드캐스트에는 어떤 프로필 필드도 싣지 않는다 — 평문 수확·사칭"* 이라고 막아둔 바로 그 위험인데, **이름 필드는 그 통제 밖에 있었다.** 프로필의 실명 필드는 막고 표시 이름의 실명은 방치한 셈이다.

### 🔴 R-18 — 고정 공개키 = 영구 재식별자

`static_pubkey` 32B는 **신원 초기화 전까지 바뀌지 않고 주기적으로 브로드캐스트**된다. 수동 관찰자는 이 값만으로 **같은 기기가 언제 어디에 나타났는지** 이어 붙일 수 있다.

⚠️ **[21 §4-3](21-identity-spec.md)에서 하드웨어 파생을 거부한 이유 4번이 "영구 추적자가 된다"였다.** MAC 랜덤화가 막으려던 추적을 **우리가 앱 계층에서 되살린 것**이다.

**다만 성질이 완전히 같지는 않다** — 사용자가 [신원 초기화](21-identity-spec.md)로 바꿀 수 있고, 앱을 끄면 광고가 멈춘다. MAC은 둘 다 안 된다. 그래도 **기본 동작이 추적 가능**하다는 사실은 남는다.

### ⚠️ 부수 발견 — `Noise_XX`의 identity hiding이 무효화된다

`Noise_XX`는 정적 공개키를 **암호화해서** 교환한다(도청자가 통신 당사자를 알 수 없게). 그런데 **우리는 같은 키를 발견 패킷에 평문으로 뿌리고 있다.** 세션 계층이 애써 숨기는 것을 발견 계층이 먼저 공개하므로 **그 성질은 우리 설계에서 이득이 되지 않는다.** 이건 결함이라기보다 **트레이드오프의 정직한 기록**이다 — 제로 컨피그 발견(DR-1)을 택한 대가다.

## 4. 실측 절차

### 4-1. 자동 회귀 (CI · 권한 불필요)

| 대상 | 방법 |
|---|---|
| W-1·W-3·W-4·W-7 | 인코더 **골든 레이아웃 테스트**(바이트 오프셋 고정) |
| W-2 | 인코딩 결과에 **금칙 문자열 목록**(이메일·전화 패턴·프로필 키) 부재 단언 |
| W-8 | **tap 링크**로 프레임을 가로채 평문 부재 단언 — 기존 `ciphertext_on_the_wire_is_not_plaintext`를 **금칙어 목록 기반으로 일반화** |
| W-11 | 실행 출력·`Debug` 문자열 스캔 |

### 4-2. 수동 캡처 (실기 · 권한 불필요) — ★ 절차 = **[`tools/wirecap.sh`](../tools/wirecap.sh)** (M1-12 · 08-15 상시화)

**우리 프로토콜은 멀티캐스트라 `sudo` 없이도 그룹에 조인해 받을 수 있다.** 이게 곧 *"공격자도 이만큼 쉽게 본다"* 는 증명이다. 그동안 여기 붙어 있던 인라인 파이썬을 저장소 스크립트로 승격했다 — 실행 수단이 상비돼야 트리거(SEC-T1)가 규약으로 성립한다.

```bash
tools/wirecap.sh 6   # 6초 수신 — 실행 중 인스턴스의 실물 패킷을 hex+ASCII로
```

**실행 시점 = SEC-T1**: 발견 와이어 포맷을 바꾼 커밋 + **발신 경로가 늘어난 커밋**(유니캐스트 S4·인터페이스별 발신 등)마다 재실행하고 판정을 journal에 남긴다.

**판정법**(스크립트가 재료를 만들고, 판단은 사람이 한다):
1. **ASCII 열** — 사람이 읽을 수 있는 것이 매직(`NXBP`)과 **표시 이름 하나뿐**인가. 이메일·호스트명 조각·전화가 보이면 그게 곧 유출이다.
2. **고정 구간 요약** — 같은 발신원의 패킷 간 불변 바이트(스크립트가 자동 표시). 알려진 고정값(매직·ver·kind·flags·**키 지문(R-18 기등록)**·tcp_port·epoch·instance(기동 무작위 · D-22)) 외의 **새 고정값 = 심사 대상**(재식별자).

**첫 실측(08-15 · 3신원 · M1-8/M1-9 반영 빌드)**: ① ASCII = `NXBP` + 표시 이름만(한글은 UTF-8이라 점 표시 · `kiros33`은 사용자 옵트인 이름) — **통과** ② 고정 구간 = 전부 알려진 필드 · 새 재식별자 없음 — **통과**. 같은 seq 사본 5부 수신 = M1-9 팬아웃(기본+인터페이스별+지향 브로드캐스트)의 같은 주기 중복(수신측 관측 멱등 — 무해).

### 4-3. 세션 구간 캡처 (실기 · 권한 필요)

```bash
sudo tcpdump -i any -A -s0 'tcp port 47200' | grep -a "보낸메시지"   # 아무것도 안 나와야 정상
```

⚠️ **W-8은 아직 실소켓 캡처로 확인하지 않았다** — 단위 테스트(tap 링크)만 통과했다. 실기 항목으로 남긴다.

## 5. 정직하게 — **숨기지 못하는 것**

암호화해도 남는 것이 있다. 이것을 "보호된다"고 말하지 않는다(NFR-S-5).

| 새는 것 | 왜 | 대응 |
|---|---|---|
| **존재와 참여 사실** | 발견은 평문 브로드캐스트다 | **설계 의도** — 이게 제로 컨피그의 대가 |
| **누가 누구와 언제 연결했는가** | TCP 연결 자체가 관찰된다 | 막을 수 없다(릴레이도 목적지는 본다) |
| **메시지 길이·타이밍** | AEAD는 내용을 숨기지 **길이를 숨기지 않는다** | 패딩은 **채택하지 않는다** — 대역폭·복잡도 대비 이득이 작다(DR-5) |
| **파일 크기·전송 시간** | 위와 같음 | 명시 |
| **`tcp_port`** | 연결에 필요 | 필수 노출 |

## 6. 반영 — 요구·리스크·할 일

| ID | 내용 |
|---|---|
| **FR-S-49** | **발견 패킷 내용물 허용 목록** — 명세된 필드 외 어떤 바이트도 싣지 않는다. 프로필·연락처·메시지·파일명 **금지**. **CI 회귀로 강제**(W-1·W-2) |
| **FR-S-50** | **표시 이름 기본값이 개인 정보를 포함하지 않는다** — 호스트명을 **그대로 쓰지 않고**, 실명 추정 부분을 제거하거나 **지문 기반 중립 라벨**을 기본값으로. 사용자가 원하면 실명 사용 가능(옵트인) + **"LAN 전체에 방송된다"는 고지** |
| **FR-S-51** | **와이어 평문 회귀** — 발견 인코더 골든 + 금칙어 스캔 + 세션 tap 평문 부재를 **매 CI에서** 검증 |
| **R-18** | **고정 공개키 주기 광고 = 영구 재식별자** — 수동 관찰자가 기기 출현을 이어 붙일 수 있다. MAC 랜덤화가 막으려던 추적을 앱 계층에서 되살린다 |
| **R-19** | **표시 이름 기본값(호스트명)이 실명을 평문 브로드캐스트**한다 — 프로필은 막았는데 이름은 통제 밖이었다 |
